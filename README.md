\# Supermart Grocery Sales Analysis



\## Project Overview

An interactive Power BI dashboard project focused on analyzing Supermart Grocery Sales data and identifying key business insights.



\## Business Objectives

1\. Supermarket Sales Overview

2\. Product Performance Analysis

3\. Discount \& Profit Analysis

4\. Geographic Performance Analysis



\## Tools \& Technologies

\- Power BI

\- Power Query

\- DAX

\- PostgreSQL (Data validation)

\- Microsoft Excel



\## Project Workflow

\- Data cleaning and preparation using Power Query.

\- Data validation using PostgreSQL.

\- Business analysis and visualization using Power BI.

\- Interactive dashboards to support business decision-making.
